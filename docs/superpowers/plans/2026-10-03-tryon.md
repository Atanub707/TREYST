# TREYST Try-On (Phase A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the bilingual try-on page (`/roynd`, `/en/try-on`) with a gallery of 10–12 license-free real jersey photos and per-jersey quote prefills (`?kit=<slug>`). No try-on buttons yet — Phase B wires the Anywear widget when the client's account/script exists.

**Architecture:** `src/data/jerseys.mjs` (slug + imported image + nameKey) drives a `JerseyCard` grid inside `TryOnPage.astro`; thin FO/EN route wrappers per the established pattern. ContactForm gains a `kit` chip/prefill mirroring the design-chip pattern. No new JS modules.

**Tech Stack:** existing site stack. No new dependencies.

## Global Constraints

- No new dependencies; no new client JS (Phase A adds none); JS/CSS budgets unchanged.
- All copy from `src/i18n/ui.mjs` (FO+EN both); no hardcoded UI strings.
- Images: license-free only (Pexels/Unsplash/Wikimedia), locally stored, optimized via astro:assets, credited in `CREDITS.md`; **no photos with prominent trademarked club/brand logos**; target 12 images, minimum 10.
- Routes added to `ROUTE_PAIRS` (`/roynd` ↔ `/en/try-on`); reciprocal hreflang asserted in the matrix test.
- Reuse existing components/tokens; every page starts dark for the nav; a11y bar unchanged (target Lighthouse a11y 100).
- Tests: `npm test` (`astro build` + `node --test tests/*.test.mjs`); commit per task.

- [ ] **Step 3: Curate and download 10–12 jersey images**

Create the directory, then source images. Candidate sources (verify each is license-free and matches the acceptance criteria):

- Pexels searches: `https://www.pexels.com/search/soccer%20jersey/`, `.../football%20shirt/`, `.../sports%20jersey%20flat%20lay/`, `.../jersey%20mockup/`
- Unsplash searches: `https://unsplash.com/s/photos/football-jersey`
- Wikimedia Commons: `https://commons.wikimedia.org/w/index.php?search=football+shirt+plain`

Download candidates (append `?auto=compress&cs=tinysrgb&w=1600` for Pexels), verify each with the loop below, and keep the best 12 (min 10). Prefer plain/neutral jerseys with no prominent brand logos.

```bash
mkdir -p src/assets/jerseys
# curl -fL "<url>" -o src/assets/jerseys/jersey-01.jpg   (repeat for each)

for n in 01 02 03 04 05 06 07 08 09 10 11 12; do
  f="src/assets/jerseys/jersey-$n.jpg"
  [ -f "$f" ] || continue
  file "$f" | grep -qE 'JPEG|PNG' || { echo "BAD FILE: $f"; exit 1; }
  sips -s format jpeg "$f" --out "/tmp/treyst-jersey-$n.jpg" >/dev/null
  mv "/tmp/treyst-jersey-$n.jpg" "$f"
  w=$(sips -g pixelWidth "$f" | awk '/pixelWidth/ {print $2}')
  h=$(sips -g pixelHeight "$f" | awk '/pixelHeight/ {print $2}')
  echo "jersey-$n: ${w}x${h}"
  [ "$w" -ge 1200 ] || [ "$h" -ge 1200 ] || { echo "TOO SMALL: $f"; exit 1; }
done
```

If fewer than 10 candidates pass, widen the searches (e.g., generic "sports shirt") — never keep a failing or clearly branded file.
